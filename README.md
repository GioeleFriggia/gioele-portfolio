# Gioele Portfolio — Milestone 1

Portfolio editoriale ispirato al ritmo visivo dei migliori portfolio Awwwards, con una struttura originale e contenuti dedicati ai prodotti enterprise/hospitality di Gioele.

## Avvio

```bash
npm install
npm run dev
```

Apri http://localhost:3000

## Personalizzazione immediata

- Cambia email in `components/Header.tsx` e `app/page.tsx`.
- Modifica progetti in `data/projects.ts`.
- Inserisci immagini in `public/images` e video in `public/videos`.
- Sostituisci i visual CSS in `components/ProjectVisual.tsx` quando avrai screenshot reali.

## Pagine incluse

- Homepage editoriale
- Profilo
- Quattro progetti
- Pagine progetto dinamiche
- Responsive mobile
- Animazioni Framer Motion
